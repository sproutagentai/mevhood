# Learning from failed research

The 25 October diagnosis recomputed 15 completed frontier trials. Each lost WETH before gas in all ten paired observations. The old planner remembered earlier hypothesis names across graph epochs, but lost their detailed outcomes and still required new proposals. The failure was in research selection; the rejections themselves were supported by the quotes.

The learning planner preserves the old evaluator and source files. A separate, replayable evidence packet retains recent rejected trials, their graph, control and exact forward source frames. It distinguishes negative gross economics, gas-dominated quotes, insufficient edge/safety margin, a missing entry trigger, unreliable sources and failure to improve the control. It does not infer fills or profit.

Repeated gross/gas failures suspend an asset cluster across fee and family variants. New positive known-net observations can reopen it, and one collector sentinel keeps that possible. Hypotheses require at least three measured observations and a quote meeting the original control's edge/gas floors. Negative or unmeasured quotes request data; they do not become obligatory strategies.

The model reviews actual failure IDs and chooses a typed next search direction. If all investigated trials failed before gas and there is no measured economic candidate, the available action is companion-pool discovery. That action reads canonical factory pools for up to six unprobed event tokens, WETH/USDG and four fee tiers. It can find older companion pools outside the recent event window. Existing pool bytecode and current liquidity are checked; new identities receive full checks. No new pool or profitable edge is guaranteed.

Other measured situations can allocate reads to a new asset cluster or independently cheaper two-leg routes. The collector preserves mandatory forward tests, applies the allocation and publishes its source frame. Pool-search completion publishes exact probes, the new graph and the number of added liquid pools. Source failures remain visible. Graph epochs wait for the requested search action before switching.

Each response may contain zero hypotheses. The original control, public freeze before future rows, seven-day / 1,000-observation gate, $1 rolling-day / $7 campaign reservations and 28 October 18:21:45 UTC stop remain unchanged. A unique owner-authorized upgrade check shares those caps and is never retried after an uncertain paid attempt. Future calls use the existing six-hour schedule.

The public learning index links the failure evidence, original model response and actual search action, including across graph epoch switches. Reproduce any linked frontier report with `npm run frontier:verify -- --report ...`. A successful test run or changed search direction does not establish improved profit.
